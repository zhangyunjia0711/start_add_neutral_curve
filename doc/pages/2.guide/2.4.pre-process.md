前处理准备
====
前处理主要是提供为计算算例准备的文件。主要包括：

* 配置文件
* 网格文件
* 基本流文件
* 输出文件目录
* 曲率文件(可选)

配置文件部分可以见相应部分的描述。

网格和基本流文件
===
网格文件和基本流文件都采用了HDF5格式。由于计算代码使用了复数来进行计算和配置，因此网格文件和基本流文件的HDF5文件在构造时，除了一开始需要给定基本的网格和流场数据以及放到对应的数据`group`（其中网格文件的`group`名为`grid`，基本流的`group`名为`baseflow`）中以外，还需要按照复数类型书写，即需要在原有数据的基础上添加一个维度表示虚部。此外，由于代码主要针对的流动特征，因此一般流场和网格文件存储上都是二维，并且都将其转化到随体坐标系下。而基本流场文件为了保证一般性，基本流变量按照如下顺序存储主要基本流变量 $\rho, u, v, w, T$.

曲率文件(可选)
===
一般的，由于输入选取在随体坐标系中，因此需要提供壁面的曲率分布文件。曲率文件可以在配置文件中的`[filenames]`字段添加`curvature`关键字的键值进行描述。为了表明可读性，该文件采用如下ascii码形式编写

```txt
1                 // 占位符
117               // 流向点数网格
0.37961  0.0      // 第1个站位的流向曲率和展向曲率
0.391033 0.0      // 第2个站位的流向曲率和展向曲率
0.28674 0.0
...
0.00250409 0.0    // 第117个站位的流向曲率和展向曲率
```

对于等曲率或者无曲率的情况，可以不必如此复杂添加曲率文件。如果是无曲率的情况，不需要提供任何信息。如果是等曲率情况，可以直接在配置[domain]字段直接添加`curvature`关键字的键值即可，具体可以写成：
```ini
...
[domain]
curvature = drx, drz ; drx和drz分别对应流向曲率和展向曲率的值
....
```
