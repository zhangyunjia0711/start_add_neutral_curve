配置文件的基本格式
===
配置文件目前采用**INI格式**。该格式的优点在于比较简单易读，容易编写。缺点在于该格式对于高级的描述结构如数组嵌套等情况不友好，无法提供相应的功能，导致目前的配置文件中二级配置标签以附加相同的关键字字头的形式来进行描述和区分。ini文件中可以添加注释，其注释的基本符号是`;`，即在注释前加分号则表示注释。

配置文件模板
====
由于配置文件采用**INI格式**，因此暂时不对其具体配置进行更详细的描述。但考虑到用户的简单使用，START提供了配置文件模板(`doc/template`目录下)，用户可以根据对应功能的配置文件模板进行调整填写。

配置文件相关键值的查找
====
配置文件的相关键值在每个功能的`cfgio_adapter.f90`文件中。具体位置以**LST**为例，该文件位于`src/lst/cfgio_adapter.f90`。该文件内提供了基本的键值的描述，用户可以根据具体的需求添加和修改键值。
