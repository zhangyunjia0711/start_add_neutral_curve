基本运行
====

基本运行比较简单，可以直接在行命令下运行程序。如果将可执行文件加入到系统环境变量，那么其基本形式为如下形式（以LST为例）：
```bash
START_LST -f [config.ini]
```
其中,

`[config.ini]`为运行工况的配置文件，用户需要自行编写或者根据例子模板改写。

`START_LST`对应于LST的运行命令。目前已有的对应各运行命令如下：

| command  | feature  |
|---|---|
|  START_LST | LST  |
|  START_LPSE | LPSE|
| START_NPSE | NPSE|
|START_OSG | optimal streak growth|

然后根据工况编写对应的配置文件并运行即可。

高级运行
====

除了以上的基本运行，程序还提供了一些高级运行功能。其基本形式是在运行命令后再添加其他运行参数来指定高级功能开关。高级功能开关主要涉及求解方法的算法优化、效率、调试以及收敛准则的调整等功能，一般情况下不影响运行结果。具体参数请参照具体程序中的相关部分，为了保证代码运行的安全，本手册不对高级运行参数进行描述。
