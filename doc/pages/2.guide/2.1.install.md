需求
===
代码安装采用需要预先安装如下软件

* linux/macos/wsl等unix terminal环境。通过cygwin也许可以安装运行，但未经过测试
* 编译器：GNU fortran9.0+或intel fortran 2018+等支持fortran2008标准的编译器
* CMake
* PETSc复数版本以及对应的SLEPc（具体安装方法请参见相关安装手册)。可以直接在线安装，也可以将对应的软件包下载后直接离线安装
* 由于NPSE使用了快速傅里叶变换（FFT），故而需要预先安装FFT的相关工具包。项目提供两种选择，一种是基于FFTW，另一种是基于MKL，默认情况下在intel编译器环境下采用MKL，在GNU编译器环境下使用FFTW。推荐通过PETSc安装FFTW。其他情况请通过在CMake安装参数中设置添加MKL宏以选定后者。
* HDF5。推荐使用PETSc安装配置脚本自动配置安装
* fortran_stdlib： Fortran标准库，提供一些简单便宜的Fortran环境下的基本函数

安装命令
===
安装基于CMake实现，在项目根目录下直接依次输入以下命令即可。
```bash
cmake -B build
cmake --build build
cmake --install build
```
install后会将对应的可执行文件安装到用户根目录下的bin目录下，但是并没有设置环境变量。如果想不再输入运行文件路径而直接运行代码，可以使用如下命令(以bash/zsh为例)：
```bash
export PATH=~/bin:$PATH
```
为了每次都可以自动配置如上信息，可以将如上语句添加到环境自动配置文件中即可。例如可以直接输入如下命令：
```bash
echo export PATH=~/bin:\$PATH >> ~/.bashrc
source ~/.bashrc
```
