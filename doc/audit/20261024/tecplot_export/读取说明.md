# Tecplot中性曲线数据

本目录的 `.plt` 是 **Preplot 2024 R1 生成的原生二进制 Tecplot 文件**；配套 `.dat` 是双精度 ASCII 复现源。所有文件已由 Tecplot 2024 R1 重新读取并导出为 ASCII，逐值比较完全一致。

| 文件 | 用途 |
|---|---|
| neutral_variable_beta_stage.plt | 总览：831站最高已知上界、334点高频下界、281点低频上界，以及其他候选/派生点/证据点，按ZONE区分 |
| neutral_variable_beta_nose.plt | 鼻部视图；第一变量是 X_plus_35_mm，配合对数x轴 |
| neutral_variable_beta_tail.plt | x≥200mm尾段的三条边界，共951个绘图点 |
| neutral_variable_beta_beta.plt | 最高已知上界对应β；在3个β赢家切换位置分ZONE，共831点，避免跨跳变连线 |
| neutral_variable_beta_all_candidates.plt | 全部1670个实际去重中性候选，保留原有负频率；建议散点显示 |

读取：在Tecplot中打开 `.plt`。横轴默认第一变量、纵轴第二变量。需要预设线/散点样式时，通过 Scripting → Play Macro/Script 运行同名 `.mcr`；同名 `.lay` 为本机保存的视图。移动目录后可重新运行 `.mcr`。

总览前三个ZONE可连线；其他候选、共轭派生点和单独的正增长证据点应使用散点。ZONE的Role/RecommendedStyle与Evidence/Boundary列记录类别。

- x单位mm；Omega、Beta均无量纲，未转为Hz。
- Evidence=0：实际中性候选；=1：共同共轭派生点，不是新增实际求解；=2：正增长证据，**不是中性点**。
- Boundary=1：局部上边界；=−1：局部下边界；=0：未分类/非中性。
- 未补鼻部第1～10站；有限谱支不等于完整全谱包络。模型与限制沿用上一级“本工况可变β计算说明.md”。

精确核对、源数据SHA和ZONE点数见 tecplot_export_manifest.json。

格式依据：Tecplot 360 2024 R1官方Data Format Guide的Ordered Data、ASCII Data File Conversion to Binary章节：
https://tecplot.azureedge.net/products/360/2024r1m1/360-data-format.html
原生读写核对采用同版本Scripting Guide中的READDATASET/WRITEDATASET命令，PRECISION=17、USEPOINTFORMAT=YES。
