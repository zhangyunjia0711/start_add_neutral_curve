## 优化工况β=20

本轮未得到所跟踪M3代表在β=20的中性闭环，因此该工况图中不绘制红色曲线。补查的已解析正β合并支，其局部剖面最大值约为 **18.89855**，位置x≈−2.37555mm、ω≈31.41109（f≈258.62175kHz）。临界β两侧±0.01的局部最大增长分别为正/负；β=20时，在该临界位置重新优化频率得到局部增长约−0.050595，冻结START独立复核一致。

以上是所跟踪代表及已解析合并支的证据。补查在远端第241截面和极前缘ξ≈4处有投影未解析，原记录保留；不把这些失败当稳定，也不宣称所有特征模态、任意频率均已获得稳定性证明。详见`optimized_positive_beta_bound.json`及evidence中的沿程记录。

## 方法与核验

沿用冻结START离散空间多项式。固定实β，以实α和实ω满足原中性方程，联合三变量bordered续接与既有β=−7所用的频率特征值方法。原生算子插值仅用于导引；逐段重新求解所有原生站交点，实际局部基流重组用于转折校正。优化β=−20鼻部改用实际剖面直接续接，避免把算子插值的多余回环交付为物理曲线。

13条新曲线逐点原生矩阵残差、原生站根数、同支向量连续性、实际剖面转折与冻结START抽查通过，所检查原方程向量残差小于1e−7。抽查中性频率两侧空间增长异号；全部已成功校正的初始中性种子都在最终曲线中匹配。β=−7两条既有闭环按原哈希复用，并各以14个原生点回代当前联合矩阵重新核对。

优化β=−30窄小闭环增加54个实际剖面中性点，共63点，逐点校正并追加独立START抽查；这些是指定基流插值模型内的细化，不是CFD网格加密或收敛证明。`point_kind=0/1/2/3`分别为原生站、实际剖面转折、独立闭合核验后的重复起点、实际剖面补充点。

多项式残差与奇异最高次系数问题的资料为[SLEPc PEP官方手册](https://slepc.upv.es/release/documentation/manual/pep.html)。本工况的方程、求导和数值结论以冻结程序实际矩阵、原始向量及独立运行结果核验，不借用该手册作为流动物理结论的证据。
