物理约定：

- `mst=1`：空间模式，复特征值为 `alpha`，增长率 `sigma=-Im(alpha)`。
- `mst=2`：时间模式，复特征值为 `omega`，增长率 `sigma=Im(omega)`。
- 中性条件 `sigma=0`，不稳定区 `sigma>0`。
- `k_flag=2`：变化 `Re(beta)`；`k_flag=4`：变化 `Re(omega)`。
- 波向角为 `atan(beta_r/alpha_r)*180/pi`。
- 名为 `GV_vector` 的输出采用 `-atan(d alpha_r / d parameter)*180/pi`。它并非直接输出群速度分量，移植前必须对照目标坐标和物理定义。

## 2. 31：neutral_curve_K

入口：`com_LST_analysis_version2.04.f90:759`；菜单调用位于148–149行。

输入来自 `ComLSTAnalysis.inp` 的31段：输出文件名、`k_flag`、有符号 `Ip`、逻辑分支开关 `I_u,I_d`。

- 正 `Ip` 沿站位编号增大方向从当前站位到最后站位，负 `Ip` 沿减小方向到站位1。
- `|Ip|` 原意是相邻站位间的细分数，但参考实现的插值基本流函数直接停止，故实际只能可靠使用 ±1。
- 初始两个站位分别从已有特征值种子求解，再找参数方向的最大增长率和两侧中性根。
- 第三个站位起，对最大增长点和上下中性分支分别按 `z_pred=2*z(n)-z(n-1)` 外推。
- 中性校正采用参数有限步长的割线更新：`dp_new=sigma_new/(sigma_old-sigma_new)*dp_old`，并限制步长大小。
- 连续100次校正未成功后，丢弃中性分支预测，回到本站最大增长率点重新寻找分支。
- 常见停止条件为 `|sigma|<1e-6`，辅助函数也允许以参数步长小于 `1e-7` 退出。

输出14列：

1. x；
2. 上分支参数、alpha_r、群速度方向角、波向角；
3. 下分支同样4列；
4. 最大增长率点同样4列；
5. 最大增长率。

输出前有 Tecplot `variables=` 表头，参数根据 `k_flag` 选择 beta_r 或 omega_r。

## 3. 32：neutral_curve

入口：`com_LST_analysis_version2.04.f90:394`；菜单调用150–151行。

站位循环、双点预测、最大增长率脊线和14列输出与31相同。输入额外包含：

- `pk0`：初始寻找最大增长率点和从该点向外寻找中性点的参数步长。
- `pk1`：预测点落在稳定区后，向不稳定区回找允许的参数变化范围。
- `pk_u,pk_d`：上、下分支继续跟踪的参数步长。
- `eps`：正增长率逼近零的容差。

与31的主要差异是中性点校正：

1. 从不稳定种子沿参数正向（上分支）或负向（下分支）前进。
2. 若跨入稳定区，则回退至前一个不稳定点，把步长除10后继续。
3. 当正增长率降至 `eps` 附近时退出。
4. 若站位外推得到稳定点，先向最大增长率所在一侧按 `pk_u` 或 `pk_d` 搜索；在 `pk1` 范围内仍找不到不稳定点则回到本站最大增长率点。

辅助函数为 `shangzhi`（1952行）和 `xiazhi`（2006行）。二者重新调用基本流加载与特征值求解；它们不提供明确失败状态或次数上限。

## 4. 33：neutral_curve_contour

入口：`com_LST_analysis_version2.04.f90:1056`；菜单调用152–153行。

输入：输出文件名、`k_flag`、`Ip`、`I_u,I_d`、`pk0,eps`。

每一站位先求参数方向最大增长率，再向参数两侧扫描整个不稳定区。所有正增长率点都被输出，而不仅是中性边界。越过零增长率时回退、步长除10，继续向中性线靠近。站位最大增长率点使用双点外推续接。

输出：`x, beta_r或omega_r, alpha_r, sigma`。这是不规则点云，适合绘制增长率等高线。原版未输出明确网格拓扑或 Tecplot Zone 结构，绘图时需三角化或规则网格采样。

## 5. 36：neutral_curve_wa_b

入口：`com_LST_analysis_version2.04.f90:1467`；菜单调用154–155行。菜单设置起止站位相同、`VTar=0`。

功能：固定站位的二维等增长率曲线延拓；菜单默认是中性曲线。

输入：输出文件名、互斥的 `I_u,I_d`、初始切向角 `angle_wb`、`ds,ds_pk0,pk_bi,pk_aoi`。

算法：

1. 从当前不稳定种子按 beta 方向找到指定上/下中性分支初始点。
2. 切向预测：`d_beta=ds*cos(angle)`，`d_p=ds*sin(angle)`。
3. 使用分段参数延拓 `goto_ThePoint` 到达预测点。空间模式 `p=omega_r`；时间模式 `p=alpha_r`。
4. 沿法向 `(-sin(angle),cos(angle))` 修正，用割线迭代使 `sigma=VTar`。
5. 法向步长最大值由 `ds_pk0` 限制，原版容差为 `|sigma-VTar|<1e-5`。
6. 根据新旧点的差分重估切向角，再前进一步。

输出：`beta_r,omega_r,alpha_r,W_vector`。时间模式实际在 `(beta_r,alpha_r)` 平面追踪，但仍输出 omega_r 字段。

原版缺少曲线闭合检测、参数边界和总点数上限，外层为无限循环。参数名称中的 `Ixe` 没有形成有效的多站位循环。

## 6. 37：neutral_curve_Ix

入口：`com_LST_analysis_version2.04.f90:1601`；菜单调用156–157行。

输入：文件名、`k=2/4`、beta 方向 `io1=±1`、omega 方向 `io2=±1`、`pk_b,pk_o,pki,eps`。

功能：固定站位，选择一个参数作为中性根的校正变量，另一参数作为等步长扫描变量。

空间模式：

- `k=2` 时，omega_r 每步改变 `pk_o`，beta_r 作为中性校正变量。
- `k=4` 时，beta_r 每步改变 `pk_b`，omega_r 作为中性校正变量。
- 根据校正变量的方向选择上分支或下分支。
- 先寻找两个中性点，之后采用两点外推预测特征值和校正参数。
- 若预测点稳定，则向不稳定区回找，再调用 `shangzhi` 或 `xiazhi` 精化。

时间模式代码有单独分支，但变量推进混用了 `pk` 和 `pk_o`，语义与空间模式不完全对称，移植时应明确以 alpha_r 作为独立实参数。

输出硬编码为 `lst/shangzhi.plt` 或 `lst/xiazhi.plt`，4列与36相同。配置中的文件名被读取但未使用。与36一样没有正常范围终止或最大点数上限。

## 7. 辅助求解器与依赖

### 7.1 特征值求解 mull

`com_OS.f90:527`。以复 alpha（空间）或复 omega（时间）为未知量，使用三个复种子和 Müller 二次插值求根，每次调用 `deva` 获得 O-S 边值问题残差。

原版以 `|delta eigenvalue|<=1e-6` 判定完成；迭代30次直接返回，调用者不能区分成功与失败。此核心应由目标求解器自己的特征值求解过程替代。

### 7.2 参数延拓 eigenvalue

`com_OS.f90:404`。参数编号：1=Re，2=beta_r，3=alpha_r，4=omega_r，5=beta_i，6=alpha_i，7=omega_i，8=站位。

每步先改变参数，再按上一次特征值割线斜率 `aug` 预测，再调用 `mull` 校正。斜率为 `(eig_new-eig_old)/dp`。第一次或切换参数时清零斜率。

### 7.3 最大增长率

`maximum_growth_rate_point` 在2780行，带可配置步长的版本 `maximum_growth_rate_point1` 在2826行。

先用小扰动判断增长率上升方向，随后按定长步长前进。当增长率未增加时反向并将步长减半。反复执行直到步长小于 `1e-7`。它是单峰局部寻优，并非多分支全局搜索。若最后最大增长率非正，原版打印消息、暂停后返回。

### 7.4 中性点

`neutral_point` 在2523行，`neutral_point_k` 在2621行。两者采用有限步长割线法求增长率零点，限制每步参数变化，并试图在首次跨入稳定区之前保持分支方向。缺少根区间、有限性和分母检查。

### 7.5 基本流与特征函数

`comFSCbaseflow`（`com_OS.f90:305`）载入当前站位的基本流及法向导数。

32、33、37 会执行 `eigenfunction` 并调用 `nhnew`。后者从 `lst/fort.13` 重新读入特征函数，以 `|u'|` 最大值对应的节点更新匹配点 `nh`。这是参考 O-S 求解器的内部匹配机制，不应直接移植到使用其他离散化或矩阵特征值方法的目标程序。

`com_OS.f90:1` 包含 `module_Plot3DRWX.f90`，但该文件不在用户提供的参考目录中。因此参考项目不能仅凭当前目录文件完整编译。

## 9. 适合不同 Fortran 求解器的移植抽象

不移植参考 O-S 矩阵、基本流数据布局或文件型匹配点机制。可以将算法拆为以下接口层：

1. `load_baseflow(station,status)`：载入目标已有站位基本流，返回错误状态。
2. `solve_eigen(state,seed,status,residual)`：在指定实参数处，使用目标求解器得到连续模态的复特征值。state 至少包含 station、Re、alpha、beta、omega、空间/时间模式。
3. `growth(state)`：统一返回 `-Im(alpha)` 或 `Im(omega)`，保留目标程序本身的无量纲尺度。
4. `neutral_root(parameter,direction,state,limits,tolerances,result)`：先搜索符号变化区间，再用有保护的割线/二分校正；返回参数、特征值、增长率、迭代数及状态。
5. `station_branches`：沿站位追踪两侧中性根和可选最大增长率脊线，对失败分支从本站种子重启。
6. `growth_contour`：输出参数平面增长率采样点及有效性，供等高线图使用。
7. `fixed_station_arclength`：切向预测、法向中性校正，配置步长、参数范围、闭合检测。
8. `fixed_station_scan`：固定一个参数的等步长序列，追踪另一个参数的中性根。
9. 输出与绘图：保留 Tecplot 兼容数据，建议额外输出 CSV 与实际配置摘要，绘图明确标注空间/时间模式、坐标、无量纲定义、分支及失败位置。

验证应覆盖：基于解析增长率的根求解和分支追踪；无根、稳定种子、特征值失败、NaN、近零割线分母和最大步数；目标求解器已有基准结果不受模块关闭状态影响；至少一个真实基本流上的中性点增长率残差检查。没有真实基本流和可信种子时，应将测试标为接口/算法验证，不能声称完成了物理曲线验证。
