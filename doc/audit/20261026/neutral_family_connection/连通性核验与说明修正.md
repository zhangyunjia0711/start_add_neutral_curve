# 中性分支连通性核验与此前解释的修正

用户提出“虚线取共轭后似乎能与实线合并”。新计算确认：**这一观察确有对应的连续中性路径。此前不能根据固定参数下A/B不互为共轭，推断它们属于不相连的物理模态族。**

## 已实际验证的连接

在两工况各自原生种子截面，从实线A的两侧中性根出发，保持原生流动剖面、固定x，连续改变有符号物理频率，且每一步都重新校正Imα=0：

**A(+100 kHz) → A(+50 kHz) → 原β=−7种子所属的零频中性边界 → B(+50 kHz)的完整共轭 → B(+100 kHz)的完整共轭。**

另独立计算了+50→0→−50kHz的较短路径，与上述长路径的±50kHz截面吻合。两工况、上下两条中性边界的8条路径均成功，未用线段替代缺失特征解。

以bluntplate x=−25.070568 mm为例，同一连续代表分支的两侧β边界为：

|有符号f/kHz|β下边界|β上边界|与旧图的对应|
|---:|---:|---:|---|
|+100|−2.430746|5.094359|实线A，+100kHz|
|+50|−8.118250|1.889502|实线A，+50kHz|
|0|−13.561108|−1.646045|此前负β零频边界|
|−50|−18.745626|−8.951248|虚线B(+50)的完整共轭|
|−100|−22.912840|−18.756253|虚线B(+100)的完整共轭|

rough在x=−25.027011mm也得到同样的连接关系。以上是在各自实际原生站位的计算，没有把两套不相同网格的站位当成完全相同位置。

## 为何图上看起来可以接起来

本程序使用exp[i(αx+βz−ωt)]。实场共轭是(ω,β,α,q)→(−ω,−β,−α*,q*)。因此，把+50kHz虚线完整取共轭后，频率也变为−50kHz。

新图左列把A(+50)和共轭B(+50)，即−50kHz的对应边界，投影到同一个x–β平面。它们确实有投影交点：按原生点折线估算，bluntplate约在x=−22.165、−13.969mm，rough约在−23.505、−14.151mm。交点只描述所画折线在二维投影中的相交，不是同一(x,β,ω)参数下的谱解重合；估计来源和相邻原生站位保存在projection_crossings.json。

新图右列保留频率坐标，展示实际重新求解的连续中性路径，明确频率从+50经0变化到−50，而不是把频率不同的两条线直接拼接后仍标注为“固定+50kHz”。

## 此前说法的准确边界

- **仍然成立：** 在固定有符号f=+50kHz、固定种子x截面，已跟踪两支分别有两个分离的β空间增长带；同一+50kHz下A/B也不是直接共轭副本。此前同参数特征值检查只证明了这一层。
- **需要修正：** 不能由此认为它们属于两个互不连通、独立的M3物理模态族。B完整共轭后与A通过频率连续变化相连，本轮中性路径已实际核验。
- **图的标签限制：** A/B只是正频率计算中不同零频种子的延拓来源标签；此前负频率曲线按共轭生成并继承标签，标签不等于跨频率保持不变的物理模态身份。实际连接在旧标签中表现为A(正频率)接到B(负频率)。
- **绘图限制：** 可以把这些截面统一作为一个连续中性族展示；不能把共轭后频率变号的边界硬拼成一条“固定+50kHz”的中性线，也不能由二维投影交叉推断全谱中性曲面已经相交。

## 数值证据

- 两工况共8条路径、840条中性记录，最大|Imα|=1.910×10⁻¹¹，最小相邻原始特征向量MAC=0.9981006。
- 沿路径在±50、±25、0kHz，以及±100、±50、0kHz作40次独立冻结START原程序抽验，最大α差=1.700×10⁻¹⁰。
- 与虚线完整共轭终点比较，最大β差=1.938×10⁻¹¹，最大α差=8.254×10⁻¹¹，终点向量共轭MAC≈1；零频处与此前独立计算的零频中性根及向量吻合。
- 原输入23项保护哈希、冻结程序哈希均复核通过。原始图、点表、矩阵、向量和已归档版本均未改写；本文件对它们的解释作补充修正。

## 复现与资料

实际代码verify.py、publish.py随结果保存。运行verify.py 50或verify.py 100；完整重算必须先把脚本的AUDIT与DEST改为新的专用目录，保留SOURCE和原生系数来源，避免覆盖已完成审计。每个进程OPENBLAS_NUM_THREADS、OMP_NUM_THREADS、MKL_NUM_THREADS均设1。算法固定原生x，使用伴随导数预测频率变化下的β，再用原空间多项式校正Imα=0，并独立验证两侧特征向量连续性和原残差；不把非中性频率轨迹当成中性路径。
