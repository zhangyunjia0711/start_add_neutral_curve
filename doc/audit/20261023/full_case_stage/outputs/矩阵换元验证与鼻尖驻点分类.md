# 同离散矩阵换元与鼻尖驻点分类

2026-10-23，Asia/Shanghai。以下是原v10空间算子的数值重建与诊断，不是修改物理模型，也未启用核心中尚受限制的wall_local temporal入口。

## 依据与代数推导

实际空间PEP使用单项式系数P(α)=P0+αP1+α²P2；这是[SLEPc PEPSetOperators](https://slepc.upv.es/release/manualpages/PEP/PEPSetOperators.html)的定义，非单项式基需另处理。已从当前工况实际导出三个系数矩阵，三组实ω实测P0=A(β)+ωG而P1/P2不变。因此在实α、β下令K=A+αP1+α²P2、M=−G，原方程等价于Kq=ωMq。该等价是对本程序导出矩阵的代数推断，并由原空间回代和向量独立验证支撑。

采用S=K−σM，显式构造OP=S⁻¹M，求其特征值μ后ω=σ+1/μ。使用SciPy LinearOperator实现实际矩阵作用，未把一般复数/非Hermitian质量阵直接作为eigs的M参数；后者有Hermitian及正定/半正定约束。[eigs官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.eigs.html)、[LinearOperator官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.LinearOperator.html)。

若w是OP的左向量，实际广义左向量为p=S⁻ᴴw；对简单本征值，直接微分Kq=ωMq并左乘pᴴ可得ωα=pᴴKαq/(pᴴMq)，ωβ同理。本项目的G不随αβ变，此前提经实际矩阵比较；否则需包含质量阵导数。左右向量必须匹配同一对，不能只取相邻打印序号。[SLEPc左向量接口说明](https://slepc.upv.es/release/manualpages/EPS/EPSGetLeftEigenvector.html)阐明左向量需相应求解支持；本试验用显式伴随OP独立计算与回代，并非宣称调用了EPSGetLeftEigenvector。

对同一简单解析色散支且ωα≠0，隐函数给αβ=−ωβ/ωα。中性驻点可求Imω=0及Im(ωβ·conjωα)=0，但后一个跨乘条件在ωα很小时天然很小，不能以其绝对量小冒称收敛。还必须检查实际Imαβ、空间β曲率，以及gω=−Im(1/ωα)。这里使用原矩阵等价关系，不使用Gaster小增长近似替代。

## 实际核验

- M1c原生i11：重建ω误差≤3.05e−13、raw-vector MAC≈1、原PEP回代残差<4e−13。
- P0频率线性相对误差约1.66e−19，P1/P2三频差0；β+.37独立实际矩阵验证二次β重建相对误差7.75e−17，G的β差1.82e−14。
